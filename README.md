## 🎯 Portfolio Blueprint

### 📦 Assignment 1: Logic, Pipelines & Processing

This section covers foundational problem-solving tasks, automated file I/O operations, and structured text manipulation routines aligned with the specific assignment requirements.

#### 🧠 Algorithmic Solutions

* **`Question 1.py`** ── Calculates student results including total marks, percentages, and letter grades. It evaluates the highest-scoring student and writes the compiled academic records to a text file.


* **`Question 2.py`** ── Analyzes string inputs to count total words, characters, and vowels. It extracts the longest and shortest words, isolates unique words to sort them alphabetically, and exports these metrics.


* **`Quesion 3.py`** ── Processes product billing by calculating subtotals and applying a 10% discount if the total exceeds 10,000. It identifies the most expensive item in the cart and generates a formatted receipt.


* **`Question 4.py`** ── Functions as an interactive, continuous calculator supporting addition, subtraction, multiplication, division, and modulus operations.


* **`Question 5.py`** ── Implements a restaurant menu ordering system for items like burgers, pizza, fries, and drinks. It calculates the subtotal based on user-defined quantities and appends the order histories to a persistent log.



#### 📊 Data & Execution Assets

* 📄 **`results.txt`** ── Stores the processed student grades, calculated percentages, and the name of the top scorer.


* 📄 **`word_analysis.txt`** ── Contains the exported sentence metrics, vowel counts, and alphabetically sorted list of unique words.


* 📄 **`bill.txt`** ── Logs the individual product calculations, applied discounts, final checkout totals, and the highest-priced item.


* 📄 **`orders.txt`** ── Acts as a continuous ledger that appends newly selected menu items, their quantities, and the financial totals.

## 🚀 How to Run locally

### 1. Replicate the Workspace

Clone the repository to your local machine:

```bash
git clone https://github.com
cd Prg4Ai-Assignments

```

### 2. Set Up the Environment

Initialize a clean virtual environment and activate it:

```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# macOS/Linux
python3 -m venv .venv
source .venv/bin/activate

```
